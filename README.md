# Keepsake — Digital & Branding Agency

Адаптивний односторінковий сайт дизайн-агенції Keepsake, створений за макетом Figma.

**Demo:** https://lesenkodasa33-gif.github.io/landing-keepsake/

## Технології

- **HTML5:** семантична структура сторінки, використання `header`, `nav`, `main`, `section`, `article`, `footer`.
- **CSS3:** стилізація, CSS-змінні, псевдокласи та псевдоелементи.
- **Google Fonts:** підключення шрифту Roboto.
- **Flexbox:** розташування елементів шапки, навігації та кнопок.
- **CSS Grid:** створення сітки робіт і блоків послуг.

## Рішення

- **Адаптивність:** використання `@media` для коректного відображення на різних розмірах екрана.
- **Контейнер:** обмеження максимальної ширини контенту та автоматичне центрування.
- **Header:** горизонтальна навігація з активним пунктом і ефектом наведення.
- **Hero:** головний заголовок, опис і кнопки переходу до відповідних секцій.
- **Галерея робіт:** CSS Grid із трьома колонками на великих екранах та адаптацією кількості колонок на мобільних пристроях.
- **Картки робіт:** окремі стилі для зображень, кольорів і ефектів наведення.
- **Секція послуг:** сітка карток із коротким описом кожної послуги.
- **Типографіка:** використання Google Fonts, налаштування розмірів, насиченості та міжрядкових інтервалів.
- **Плавність:** використання `transition` для інтерактивних елементів.
- **Структура:** розділення HTML та CSS для зручності підтримки проєкту.
